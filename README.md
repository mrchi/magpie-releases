# magpie-releases

Signed builds of [magpie](https://github.com/yetone/magpie). The source lives
in a private repository; pushing a `v*` tag there triggers the workflow here,
which builds, signs, notarises and publishes the release.

Download the latest from [Releases](https://github.com/yetone/magpie-releases/releases/latest):

- macOS, Apple Silicon: `magpie-darwin-arm64.dmg`
- macOS, Intel: `magpie-darwin-amd64.dmg`
- Terminal only: `magpie-cli-<os>-<arch>`
